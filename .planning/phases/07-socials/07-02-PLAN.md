## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent/third-party text -> DOM | post text, source names, metrics, last_error rendered |
| browser -> server actions | owner inputs |
| URLs from payloads -> links | remote_url, source links, post ids in hrefs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-10 | Tampering/XSS | all socials + approval UI | mitigate | render as text nodes only, no dangerouslySetInnerHTML, Markdown preview plain text |
| T-07-11 | Tampering | external links | mitigate | rel="noopener noreferrer", https-only and host-validated remote_url, post id validated before building /socials?post= links; Open TikTok uses constant URL with no content |
| T-07-12 | Tampering | approve with failing checks | mitigate | validateSocialDraft blocks Approve; server re-checks via zod+checkVariant |
| T-07-13 | Information Disclosure | Settings credential forms | mitigate | password input for secret, last-4 only, no values echoed back in props |
| T-07-14 | Spoofing | TikTok connect return flags | accept | fixed-string toast flags only, no data carried |
| T-07-SC | Tampering | npm installs | accept | no new dependencies |
</threat_model>
