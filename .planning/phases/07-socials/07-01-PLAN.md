<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> server actions | owner input (URLs, text, times) |
| LifeOS -> LinkedIn/Meta/TikTok | outbound API calls with stored tokens |
| repo/event/project content -> agent | untrusted text feeding drafts |
| TikTok -> callback route | OAuth redirect params |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Information Disclosure | tokens in connections | mitigate | AES-256-GCM via crypto.ts, last-4 only, never logged or in errors, never .env |
| T-07-02 | Tampering | agent posting without consent | mitigate | socials.publish is APPROVE with LOCKED variantId/platform, content floor, zod+checkVariant re-check at approval |
| T-07-03 | Tampering | prompt injection from repo/event content | mitigate | untrusted envelope + drafted_from_content flag, publish still needs approval |
| T-07-04 | Repudiation/Duplicate | double post on retry | mitigate | approval:{id} idempotency, publishing state, IG container reuse, LinkedIn never auto re-post |
| T-07-05 | Tampering | scheduled job after edit/cancel | mitigate | job re-validates status, approval id, text hash |
| T-07-06 | Spoofing | TikTok OAuth CSRF | mitigate | state cookie (+PKCE), fixed hosts, fixed error strings |
| T-07-07 | SSRF/Injection | mark-posted URL, image URL | mitigate | https + platform-host validation; LifeOS never fetches image URL; constant API URLs only |
| T-07-08 | Information Disclosure | provider error bodies | mitigate | map to fixed strings, no raw provider output stored in last_error |
| T-07-09 | Elevation | server actions without session | mitigate | session guard + zod on every action, audit log |
| T-07-SC | Tampering | npm installs | accept | no new dependencies added (plain fetch) |
</threat_model>
