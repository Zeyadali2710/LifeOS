## Sampling Rate

- **After every task commit:** quick unit command + the DB file the task touches (`npx vitest run tests/db/<file>`), plus `npx tsc --noEmit` when kinds/types change
- **After every plan wave:** `npx vitest run tests/unit && npx vitest run tests/db && npx eslint . && npx tsc --noEmit`
- **Before `/gsd:verify-work`:** full suite incl. `npx playwright test` green, then owner VM DB run
- **Max feedback latency:** 120 seconds (per-task commands)
