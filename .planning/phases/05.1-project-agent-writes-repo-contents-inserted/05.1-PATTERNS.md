### `src/server/agents/tools/github.ts` — `github.list_tree`, `github.get_file` (READ, live GitHub)

**Analog:** `getPullRequest` in the same file.

**Imports already present** (L1-7) — add nothing except `GithubError` from `../../github/client` if mapping errors:
```typescript
import { createGithub } from "../../github/client";
import { getConnections, readToken, writeToken } from "../../github/connections";
import { ToolError, type Tool, type ToolContext } from "../types";
```

**Reuse helpers** (L9-33): `NOT_CONNECTED`, `cut`, `repoArg`, `repoRow` (throws `ToolError("not_found", "Unknown repository …")`), `resolveRepo`.
```typescript
async function repoRow(ctx: ToolContext, repo: string) {
  const [r] = await ctx.handle.select().from(githubRepos).where(eq(githubRepos.fullName, repo));
  if (!r) throw new ToolError("not_found", `Unknown repository ${repo}`);
  return r;
}
```
`repoRow(...).defaultBranch` is the branch (D-02) — no `ref` input.

**Core live-read pattern** (L190-206) — copy shape exactly:
```typescript
const getPullRequest: Tool<{ repo: string; number: number }, ListOut> = {
  name: "github.get_pull_request",
  label: "Reading pull request details",
  description: "...",
  input: z.object({ repo: repoArg, number: z.number().int().positive() }),
  output: listOut,
  tier: "READ",
  sideEffect: false,
  resolve: resolveRepo,
  async handler(i, ctx) {
    const token = await readToken(ctx.handle);
    if (!token) return { connected: false, message: NOT_CONNECTED, items: [] };
    const gh = createGithub({ token, fetch: ctx.fetch });
    const pr = await gh.get(base, prDetail);
    if (pr.status !== 200 ...) throw new ToolError("unavailable", "GitHub returned no data");
```
New tools get their own output schemas (RESEARCH Pattern 1): `list_tree` → `{ connected, message?, repo, branch, truncated, entries }`, `get_file` → `{ connected, message?, repo, path, truncated, untrusted: true, content }`. NOT_CONNECTED envelope must still carry `repo` (D-05 taint scan). Decode/size/binary logic: RESEARCH Pattern 1 sketch (`Buffer.from(b64,"base64")`, `TextDecoder("utf-8",{fatal:true})`, `FILE_CAP=16_384`, `TREE_CAP=400`, `NOISE` regex). Do NOT set `private: true` on these (privacy flows via `repo` name, D-05).

**Client constraint** (`src/server/github/client.ts` L25-27, L59-64): `checkPath` requires leading `/` and no `://`; `get()` zod-parses JSON and returns `{status:200,data}`. Paths must be encoded per segment before concatenation.

**Error mapping** — `GithubError.kind` values (`client.ts` L5): `"auth" | "rate_limit" | "not_found" | "server" | "network" | "client"`. Map `not_found` → `ToolError("not_found", "Not found on the default branch: {path}")`, 403 `client` → Contents permission message.

**Registration** (L275-277): append to the array in `githubTools`:
```typescript
[listRepos, listPrs, listIssues, recentCommits, ciStatus, getPullRequest, createIssue].map((t) => [t.name, t]),
```
