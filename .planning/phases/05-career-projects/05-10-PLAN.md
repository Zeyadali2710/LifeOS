<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| URL param -> DB | project id is attacker-controllable |
| LifeOS -> owner's terminal (clipboard) | copied launch command / brief |
| owner URL links -> DOM | owner-entered http(s) links |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-34 | Elevation of privilege | /projects/[id] | mitigate | `await requireOwner()`; mutations via owner-checked actions |
| T-05-35 | Tampering / DoS | id param | mitigate | `z.uuid()` guard before query -> notFound (no pg error/500) |
| T-05-36 | Tampering (shell injection) | Copy launch command | mitigate | command built server-side by launchCommand() which returns null on metacharacters; payload refine at write time; copy-only, no protocol launch (D-14) |
| T-05-37 | Tampering (XSS) | brief preview, URL links | mitigate | brief rendered as plain text (no markdown/HTML); links validated http(s) at write and rendered with rel=noopener noreferrer |
| T-05-38 | Information disclosure | clipboard on insecure origin | accept | owner-only data; fallback is manual selection; deployed over tailscale serve HTTPS (secure context) |
</threat_model>
