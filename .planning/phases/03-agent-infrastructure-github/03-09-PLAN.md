## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-34 | Spoofing | repo argument | mitigate | resolve() against github_repos and write-token repo list before approval creation |
| T-03-35 | Elevation of privilege | write token | mitigate | writeToken only inside create_issue (grep gate); handler requires approvalId so it cannot run from the plain gateway path |
| T-03-36 | Tampering (duplicate write) | create_issue retries | mitigate | approval-id marker + adopt pre-check on ambiguous retry (AGT-03) |
| T-03-37 | Tampering (prompt injection) | READ outputs | mitigate | bounded/truncated outputs; system prompts mark tool results as data (registry, plan 02); loop wraps results (plan 11) |
| T-03-38 | Information disclosure | tool outputs | mitigate | outputs carry only public metadata fields + html urls; no tokens |
</threat_model>
