## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| browser -> /api/chat | prompt text, threadId |
| server -> browser (NDJSON) | answers and trace containing untrusted GitHub text |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-54 | Spoofing | chat/threads/status routes | mitigate | auth().api.getSession per request, 401 JSON (proxy is optimistic only) |
| T-03-55 | Tampering (CSRF) | POST /api/chat | mitigate | require application/json content-type + Origin must equal request origin + SameSite=Lax cookie |
| T-03-56 | Denial of service (cost) | POST /api/chat | mitigate | 8000-char prompt cap, 10 runs/minute, no-key/paused/cap preflight before any LLM call |
| T-03-57 | Information disclosure | NDJSON events | mitigate | DTOs only (no messages, tokens); summaries redacted server-side |
| T-03-58 | Tampering (IDOR) | /api/threads/[id] | accept | single-owner app; ids validated as uuid; no cross-user data exists |
</threat_model>
