## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-SC | Tampering | npm install @anthropic-ai/sdk | mitigate | RESEARCH audit Approved (first-party, ADR-008); `npm view ... scripts.postinstall` must be empty and repository must be anthropics/anthropic-sdk-typescript before install; output recorded in SUMMARY |
| T-03-05 | Elevation of privilege | resolvePolicy | mitigate | HIGH_RISK floor in a pure function with unit tests (AGT-01) |
| T-03-06 | Information disclosure | tool I/O stored/displayed | mitigate | redact() strips token/authorization/secret/password/key values; summaries capped at 600 chars |
| T-03-07 | Information disclosure | ANTHROPIC_API_KEY | mitigate | env only (ADR-007), optional, never serialized; llm.ts is the only reader |
| T-03-08 | Tampering (open redirect / XSS) | GitHub links | mitigate | isSafeGithubUrl requires https + exact github.com host, no credentials |
| T-03-09 | Denial of service (cost) | unknown model id | mitigate | costUsd falls back to the most expensive price so the cap is never under-counted |
