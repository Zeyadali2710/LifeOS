## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-02-16 | Information disclosure | GET routes + SSE | mitigate | auth().api.getSession per request (proxy is optimistic only); 401 JSON |
| T-02-17 | Elevation of privilege | server actions | mitigate | `await requireOwner()` first in every action |
| T-02-18 | Tampering | action inputs | mitigate | zod uuid/boolean/iso datetime; snooze bounded to (now, now+30d] |
