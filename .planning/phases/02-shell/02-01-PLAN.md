<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| app -> Postgres NOTIFY | payloads visible to any DB session that LISTENs |
| hub -> subscribers | rows fan out to SSE streams (consumer authenticates in plan 05) |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information disclosure | NOTIFY payload | mitigate | payload is {k,id} only; row is re-read by the hub (also avoids 8000-byte cap) |
| T-02-02 | Tampering | hub notification handler | mitigate | JSON.parse in try/catch, k whitelist, id typeof check, loadEventRow returns null for non-uuid |
| T-02-03 | Denial of service | LISTEN connections | mitigate | single dedicated client per process on globalThis; backoff capped 30s; keepalive detects half-dead TCP |
| T-02-04 | Repudiation/availability | emitActivity | mitigate | never throws (callers like auth hook must not fail); failures logged via pino with redaction |
</threat_model>
