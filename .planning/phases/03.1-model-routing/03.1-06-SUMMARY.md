# Phase 3.1 Plan 06: Mid-run routing Summary

advance() now gates free turns on private data, retries/falls back on free errors, validates free turns before storing them, and switches once and permanently to Sonnet (persisted, visible as a route step); Free-only pins fail instead.

## What was built
- `switchToSonnet(kind, reason)`: appends a RouteEvent (seq = toolCount + 0.5), updates `agent_runs.model` (so resume stays on Sonnet), notifies live, emits the route step. Pinned Free-only runs get a `blocked` event and fail with `free_unavailable` / `private_blocked`. `curModel` is now `let`.
- Pre-turn gate: before any free request is built, `mentionsSensitive(messages, sensitiveRepoNames)` (private true or null) with opt-in off switches to Sonnet first.
- Taint: `saw_private` set at run start (prompt/history) and after every tool-result message, for every model, regardless of opt-in.
- Free stream errors: one transient retry (Retry-After capped at 5 s), then `markFreeUnavailable` on transient/429/402 and fallback; aborts rethrow; non-free path unchanged.
- Free turns: system gets `FREE_SUFFIX`; tools get `escalate` only for Auto runs. After `addUsage` (so dropped turns are billed in run_turns) an escalate or failed `checkFreeTurn` drops the turn (never pushed) and switches.
- Route steps of existing events re-emitted at run start.
