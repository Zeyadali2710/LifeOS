## Pattern Assignments

### `src/server/agents/openrouter.ts` (service, request-response)

**Analog:** `src/server/agents/llm.ts` lines 1-34. Same `LlmClient` contract (`types.ts` 23-29), same `LlmTurn` return shape.

**Contract to satisfy** (`types.ts` 18-29):
```typescript
export type LlmUsage = { input: number; output: number; cacheWrite: number; cacheRead: number };
export type LlmTurn = { content: Anthropic.ContentBlock[]; stopReason: string | null; usage: LlmUsage };
export type AnthropicTool = { name: string; description: string; input_schema: Anthropic.Tool.InputSchema };
export interface LlmClient {
  stream(params: { model: string; system: string; messages: Anthropic.MessageParam[]; tools: AnthropicTool[]; maxTokens: number },
    onText: (t: string) => void, signal?: AbortSignal): Promise<LlmTurn>;
}
```

**Factory shape to copy** (`llm.ts` 5-9, 22-31): factory takes injectable deps (`apiKey` there; here `{getKey, fetch}`), returns `{ async stream(p, onText, signal) {...} }`, returns the usage object with the four fields:
```typescript
return {
  content: m.content,
  stopReason: m.stop_reason,
  usage: { input: ..., output: ..., cacheWrite: ..., cacheRead: ... },
};
```
OR text blocks must be `{ type: "text", text, citations: null }` (see `tests/helpers/fake-llm.ts` 25-26 which builds the same shape). `tool_use` blocks: `{type:"tool_use", id, name, input}`; `apiName()` (`types.ts` 60) maps dotted names to underscores, already applied in `toAnthropicTool`, so tool names pass through unchanged.

**Injected fetch pattern:** `AdvanceOpts.fetch?: typeof fetch` / `ToolContext.fetch` (`types.ts` 37, `loop.ts` 82). Use `opts.fetch ?? fetch` so unit tests inject a fake.

**Translation, timeout, error classification:** no codebase analog; follow RESEARCH.md "Translation" and "OpenRouter API facts" sections. `FreeModelError` class: copy the `ToolError` shape (`types.ts` 8-16: `class X extends Error { constructor(public code, message?) {super(message ?? code); this.name = ...} }`) adding a `transient: boolean`.

**Settings key read/write pattern** (`spend.ts` 7, 35-47):
```typescript
const CAP_KEY = "ai.spend_cap_usd";
export async function getCap(handle: DB = db()): Promise<number> {
  const [r] = await handle.select({ v: settings.value }).from(settings).where(eq(settings.key, CAP_KEY));
  return typeof r?.v === "number" ? r.v : DEFAULT_CAP;
}
export async function setCap(handle: DB = db(), usd: number): Promise<boolean> {
  ...
```

## Shared Patterns

### Owner-only server actions
**Source:** `src/server/settings-actions.ts` 62-72. `await requireOwner()` first, zod `safeParse`, `try/catch` with `log.error({ err }, "...")` returning `{ ok: false }`. Never log secrets. Apply to all new actions.

### Encrypted secret storage
**Source:** `src/server/github/connections.ts` 41-44, 54-57; `encrypt`/`decrypt` from `../crypto`. Apply to the OpenRouter key; decrypt per call in the OR client's `getKey` (rotation without redeploy).

### Settings table flags
**Source:** `src/server/agents/spend.ts` 35-47 and `runs.ts` 10-22. Apply to `ai.free_private_ok` and any persisted cooldown.

### Audit
**Source:** `connections.ts` 44, 51: `await audit({ actor: "owner", action: "...", target, metadata })`. Apply to key save/remove and toggle change.

### Persist-then-notify on run state change
**Source:** `loop.ts` 121 and 144-145 (`await notifyLive(h, "run", runId)` after each DB update that the UI shows) and `emit` wrapper 93-100 (guards aborted signal and swallows onEvent errors). Apply to route/switch events.

### Redaction (D-11)
**Source:** `src/server/agents/redact.ts` (applied at tool/gateway level). The OR path receives the same Anthropic-format history, so redaction already applied. Planner must confirm by reading `redact.ts`/`gateway.ts` and add a test that the OR request body contains no token (not read here).
