## Sampling Rate

- **After every task commit:** Run quick run command (plus the task's own test file)
- **After every plan wave:** Run full suite command (db tests on VM)
- **Before `/gsd:verify-work`:** Full suite green + one live OpenRouter smoke run on the VM
- **Max feedback latency:** 60 seconds
