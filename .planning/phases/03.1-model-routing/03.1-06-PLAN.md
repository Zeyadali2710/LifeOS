## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LifeOS -> free provider | each free turn sends the conversation |
| free model output -> tool gateway | tool calls proposed by an untrusted, possibly prompt-injected model |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3.1-23 | Information disclosure | private repo data -> free model | mitigate | pre-turn mentionsSensitive scan over the whole conversation with null=private; switch (or fail when pinned) before any request; DB test asserts free calls never contain the private name |
| T-3.1-24 | Elevation of privilege | prompt injection steering escalate | mitigate | escalate only switches to Sonnet; Sonnet has the same allowed tools, tiers and approval gates; reason stored as data, sliced to 200, never added to a system prompt |
| T-3.1-25 | Tampering | invalid/forged tool calls | mitigate | checkFreeTurn validates names and zod inputs before storing; gateway re-validates and enforces tiers; APPROVE tools still need owner approval (D-02) |
| T-3.1-26 | Information disclosure | secrets in tool output | mitigate | tool results are built from redact()ed tool_calls rows (gateway/approvals), same path for both providers; DB test asserts "[redacted]" |
| T-3.1-27 | Repudiation (cost) | dropped free turns | mitigate | usage recorded via addUsage before validation, so every turn is in run_turns |
| T-3.1-28 | Denial of service | retry storms on 429 | mitigate | one retry per run, Retry-After capped at 5 s, cooldown after 429/402 |
</threat_model>
