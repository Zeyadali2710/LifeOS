<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LifeOS server -> OpenRouter / free provider | prompts (tool data) leave the trust boundary to a third party that may log |
| OpenRouter response -> loop | untrusted model output (tool names/args/text) enters the system |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3.1-04 | Information disclosure | OpenRouter key in transit/logs | mitigate | key only in Authorization header over HTTPS to a constant URL; never in body, error messages or logs; test asserts body excludes key |
| T-3.1-05 | Information disclosure | free provider logging prompts | mitigate | provider.data_collection "deny" sent first (D-10); real control is the D-09 gate in plan 06 |
| T-3.1-06 | Tampering | malformed tool-call args | mitigate | arguments must parse to a plain object else FreeModelError invalid_tool_call; ids regenerated so provider ids can't collide with idempotency keys (runId, toolUseId) |
| T-3.1-07 | Spoofing (SSRF) | request URL | mitigate | URL is a module constant; model id never selects the host |
| T-3.1-08 | Repudiation (cost under-count) | pricing | mitigate | :free = $0 only when provider reports no cost; otherwise Opus price; unknown ids Opus |
| T-3.1-09 | Denial of service | hung free endpoint | mitigate | 45 s AbortSignal.timeout per call |
</threat_model>
