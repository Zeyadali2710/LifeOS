<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| event text -> LLM context | attacker-authored titles/descriptions (invites, shared calendars) reach the model (prompt injection) |
| LLM -> tool gateway | model-chosen tool calls and arguments |
| private data -> free model provider | third-party free models may log prompts |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-47 | Tampering (prompt injection -> writes) | calendar write tools | mitigate | every agent write is APPROVE or HIGH_RISK; owner sees the full payload (and before/after) in the approval; DATA_RULE + untrusted-text line in the prompt; handlers refuse without approvalId |
| T-04-48 | Elevation of privilege | delete tier downgrade | mitigate | delete_event tier HIGH_RISK; resolvePolicy floors it; test proves a READ override cannot lower it |
| T-04-49 | Tampering | model-supplied calendarLabel/provider/etag | mitigate | resolve overwrites locked fields from the DB; checkLocked blocks edits to them (04-01) |
| T-04-50 | Information disclosure | calendar output to free models | mitigate | Tool.private taints the run; D-09 gate switches to Sonnet unless ai.free_private_ok; test asserts free requests never contain event titles |
| T-04-51 | Information disclosure | secrets in tool output | mitigate | tools read DTO-level data only (no connections access beyond status); test scans tool_calls outputs for seeded secrets |
</threat_model>
