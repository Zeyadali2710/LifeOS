<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| Google -> callback route | attacker-controllable query params (code, state, error) arrive at the server |
| server -> Google APIs | bearer tokens leave the server to fixed hosts |
| Google event JSON -> DB | untrusted calendar content (shared invites) |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-24 | Spoofing (OAuth CSRF / code injection) | callback route | mitigate | owner session required on start and callback; state in an encrypted single-use HttpOnly SameSite=Lax cookie, 10-minute TTL, timingSafeEqual compare; PKCE S256 verifier never leaves the server |
| T-04-25 | Information disclosure | refresh/access tokens | mitigate | encrypted in connections via saveCalendarSecret; never in logs, audit, DTOs, redirects or error messages |
| T-04-26 | Elevation of privilege | OAuth scopes | mitigate | only calendarlist.readonly + calendar.events requested; callback rejects grants missing either; no full calendar scope |
| T-04-27 | Tampering (open redirect) | callback redirect targets | mitigate | every redirect built from BETTER_AUTH_URL + fixed paths; never from request.url or params |
| T-04-28 | Server-side request forgery | Google client | mitigate | fixed hosts as constants; checkPath rejects absolute/`//` paths; ids encodeURIComponent'd |
| T-04-29 | Repudiation / duplicate writes | agent create retries | mitigate | deterministic event id from approval id; 409 adopts the existing event (AGT-03) |
</threat_model>
