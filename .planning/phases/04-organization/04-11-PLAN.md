<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| owner browser -> connectIcloud | Apple ID and app-specific password cross into the server once |
| iCloud CalDAV -> parser | remote ICS (incl. shared calendars/invites) is untrusted |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-30 | Information disclosure | iCloud app-specific password | mitigate | encrypted at rest; decrypted only inside realDav's closure; never in DTO, audit (metadata {id, account}), logs, lastError or tool output; form clears it on submit (plan 04-14) |
| T-04-31 | Server-side request forgery | DAV URLs from discovery/responses | mitigate | serverUrl constant https://caldav.icloud.com; every collection/object URL must be https and end with .icloud.com before any request |
| T-04-32 | Tampering (lost update) | PUT/DELETE | mitigate | If-Match with stored etag, If-None-Match on create; 412 surfaces conflict, never blind overwrite |
| T-04-33 | Denial of service | huge/malicious ICS | mitigate | 256 KB per-resource cap, per-resource try/catch, 5000-object cap, counts-only logging |
| T-04-34 | Tampering (ICS/CRLF injection) | writes | mitigate | content produced only by recurrence-edit (ical.js setters, T-04-13) |
</threat_model>
