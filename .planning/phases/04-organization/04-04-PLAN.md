    - cases: A 9-10 + B 10-11 -> []; A 9-11 + B 10-12 -> one pair window 10-11; nested A 9-12 + B 10-11 -> one pair; three-way overlap -> three pairs; all-day/transparent/declined/cancelled inputs -> [] after busyOf

    - `type PlanTask = { id: string; title: string; dueAt: number | null; dueHasTime: boolean; priority: 1 | 2 | 3 | null; createdAt: number; estimateMin?: number }`
    - `type PlanItem = { kind: "task"; taskId: string; start: number; end: number; why: Why } | { kind: "conflict"; taskId: string; dueAt: number; why: Why }` with `type Why = { key: "due_first_slot" | "priority_due" | "only_block" | "no_slot"; params: Record<string, string | number> }`
    - `planDay({ tasks, slots, skipped = new Set<string>(), dayEnd })`: order dueAt asc (nulls last), priority asc (1 first, null last), createdAt asc; skip ids in `skipped`; length = estimateMin ?? 30 min; first-fit into remaining slots, consuming the used part; a dated task only fits if end <= dueAt; unplaced tasks with dueAt <= dayEnd become `conflict` items with why no_slot; unplaced undated or later-due tasks are omitted. why: priority 1 -> priority_due {priority:"high", due}; the only fitting slot before the due time -> only_block; otherwise due_first_slot {due, minutes: slot length in minutes}. Deterministic: same input -> same output (ties never reshuffle)
    - `weekStats(items: SchedItem[], days: string[], now)`: `{ events: count of non-declined, non-cancelled items starting in the week; freeHours: sum of freeSlots over each day's waking window (whole day, no now clip), rounded down to whole hours; conflicts: conflicts(busyOf(items)).length }`
    - `headline(slotsToday, slotsTomorrow, now)`: largest slot >= 120 min later today -> "You're free this morning." / "this afternoon." / "this evening." (start < 12:00 morning, 12:00-17:00 afternoon, >= 17:00 evening); else tomorrow -> "You're free tomorrow {morning|afternoon|evening}."; else null (caller chooses "Your schedule is full today." or the no-calendar/no-event variants per UI-SPEC)
    - `planSummary({ freeMinutes, toPlace, unplaced, afterHours, open })` returns exactly one UI-SPEC template: `{h} hours free between now and 22:00. {n} tasks to place.` / `Your day is full. {n} tasks have no free slot today.` / `All clear. Nothing due today.` / `Today's plan is done. {n} tasks are still open.` with singular forms (`1 task`, `1 hour`)
