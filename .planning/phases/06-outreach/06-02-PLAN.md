| Boundary | Description |
|----------|-------------|
| owner-supplied URL -> outbound request | feed and import URLs reach the network from the server/worker |
| third-party HTML/mail -> text | untrusted markup converted to plain text |
| agent/owner text -> MIME headers | subject/body/names become RFC 2822 headers |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-05 | Information disclosure / EoP (SSRF) | safeGet | mitigate | connect-time guardedLookup + BlockList, literal-IP check, isSafeUrl per hop, ≤3 redirects; unit tests for each blocked class |
| T-06-06 | Denial of service | safeGet | mitigate | 2 MB byte cap, 15 s total timeout |
| T-06-07 | Information disclosure | feed URLs with tokens | mitigate | fixed error strings; URL never logged or embedded in errors |
| T-06-08 | Tampering (XSS / tracking) | htmlToText / bodyText | mitigate | tags stripped to text, images dropped, links shown as text (D-24) |
| T-06-09 | Tampering (header injection) | buildReplyMime | mitigate | CR/LF stripped from every header value; unit test with injected Bcc |
| T-06-10 | Denial of service | mail body size | mitigate | capUtf8 16 KB on a code-point boundary |
