## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| worker -> owner-supplied feed URLs | outbound fetch of arbitrary https URLs |
| worker -> Eventbrite/Luma | keyed API calls with stored secrets |
| third-party event data -> DB | untrusted titles/descriptions stored |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-28 | Information disclosure (SSRF) | icsProvider | mitigate | only safeGet (connect-time IP guard, redirect re-check, 2 MB); grep gate forbids raw fetch(url) |
| T-06-29 | Information disclosure | keys / feed URLs | mitigate | decrypted only in memory; logs carry `{ err, kind }` only; errors fixed strings |
| T-06-30 | Tampering | owner pipeline state | mitigate | sync never writes stage/dismissedAt/calendarEventId (grep gate + DB test) |
| T-06-31 | Spoofing (mock passed off as real) | mock providers | mitigate | isMock true on every mock row, merge keeps is_mock only when both sides mock; badges in UI plans |
| T-06-32 | Denial of service | many sources / big feeds | mitigate | per-source isolation, 500/feed cap, 6-hour singleton schedule |
| T-06-33 | Spoofing (keyed API host) | Eventbrite/Luma | mitigate | fixed host constants; token only in Authorization / x-luma-api-key header |
</threat_model>
