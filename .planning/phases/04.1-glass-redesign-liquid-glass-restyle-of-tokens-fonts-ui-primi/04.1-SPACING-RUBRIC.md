# 04.1 Spacing / radius / padding rubric (owner feedback, 2026-10-12)

Owner: "the spacing in all the cards is slightly off, some are not centered; border radius of some cards is not cohesive; some cards have a grayish box poking out; double check all spacing, radius and padding."

This rubric wins over `design/glass/*.dc.html` where they disagree (the design itself mixes 14/22/26 card radii). Use the design files for layout and content order only.

## Radius (one scale, no one-offs)

| Element | Class |
|---|---|
| Page-level card surface (any `glass-card`, list container, calendar grid, empty state card, plan/tasks card, priority/project/agent/stat card, settings card, approval detail, run detail) | `rounded-24` |
| Overlay (dialog, AI panel, notifications, palette, bottom sheets) | `rounded-30` |
| Popover / dropdown menu | `rounded-24` + `p-1.5`; its items `rounded-[18px]` (concentric: 24 − 6) |
| Item nested in a list container with `p-2` (list rows, selectable options) | `rounded-16` (concentric: 24 − 8) |
| Item nested in a padded card (`p-4`/`p-5`): inner panels, previews, plan items, textareas | `rounded-14` |
| Buttons, icon buttons, segmented controls (container AND options), chips/pills, text inputs, selects | `rounded-full` |
| Tags/badges with square look (P1, category tags) | `rounded-6` |
| Calendar event blocks | `rounded-8` |
| Colour swatches / dots | `rounded-[2px]` or `rounded-full` (unchanged) |

Never: `rounded-9`, `rounded-10`, `rounded-12`, `rounded-20`, `rounded-22`, `rounded-26`, `rounded-28` on surfaces (tooltips may keep `rounded-10`).

## Padding

- Card surface: `p-5` standard; dense/list-ish cards `p-4`. Lists of rows: container `p-2`, rows `px-3 py-2.5`.
- Card header row (eyebrow + meta + action) inside a card: first child, `mb-3`, `items-center`.
- Dialog: `p-6`. Overlay header: `h-14 px-5`. Overlay body: `px-5`.
- Never asymmetric padding unless content requires it (e.g. icon-left pills `pl-3 pr-3.5` is fine).

## Spacing

- Page wrapper: content max width per page; vertical stack of sections `gap-8` (32px).
- Inside a section: section header row → content `gap-3.5` (14px). Section header row = eyebrow (11px, `font-medium tracking-[.14em] uppercase text-text-3`) + optional meta (10.5px text-text-4) + `flex-1 h-px bg-white/[.06]` rule + optional action.
- Grid of cards: `gap-3` (12px). Two-column page layouts: `gap-6` (24px).
- Page header block (eyebrow → H1 → lead): eyebrow then H1 `mt-2.5`, lead `mt-2.5`. Header block → first section: 32px (Organization: 20px, it has a legend row).
- Toolbar controls next to a page title: in the same flex row with `items-end` (bottom-aligned with the title block), never top-aligned against the header bar. Control height `h-8` (icon buttons `size-8`, coarse pointer `size-11`), gap `gap-2`.
- Segmented control: container `rounded-full p-[3px] border border-white/[.06] bg-white/[.04]`, options `h-[26px] px-3.5 rounded-full text-[12.5px]`.

## Centering

- Icon + text rows: `items-center`. Icon-only buttons: `grid place-items-center`.
- Empty states: content centered on both axes (`flex flex-col items-center justify-center text-center`), icon → title `mt-3`, title → body `mt-1.5`, body → actions `mt-4`, actions centered.
- Numbers in circles (calendar day numbers, avatars): `grid place-items-center`.

## Glass

- Every page card uses `glass-card` (now `rgba(255,255,255,.045)` + `blur(30px) saturate(160%)`). No opaque card fills (`#0b0b0d`, `#16161a`, `rgba(28,28,32,1)`, `bg-[#...]`) on cards or cells.
- To tint a card (e.g. Today's plan cyan, first priority), keep `glass-card` and add the tint as an overlay: `relative overflow-hidden` on the card plus `before:pointer-events-none before:absolute before:inset-0 before:bg-[linear-gradient(...)]` with the content in a `relative` wrapper so it paints above the tint. Never replace the glass background with an opaque gradient end-stop.
- Nothing may poke outside a card's rounded corners: sticky headers, inner scrollers, full-bleed bars and highlighted rows must be clipped by `overflow-hidden` on the card or carry the matching radius.
- Do not add `backdrop-blur-*` / `backdrop-filter` in .tsx; blur comes only from the `glass-*` utilities.
- Links: global `a` is cyan with no underline. Nav-like links/rows must set their own text colour class.
