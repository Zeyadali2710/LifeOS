# Phase 4.1: Glass redesign - Context

**Gathered:** 2026-10-12 (from the owner's conversation; no discuss-phase run)
**Status:** Ready for UI-SPEC

<domain>
## Phase Boundary

Re-skin and re-lay-out the whole app to the owner's new "liquid glass" hi-fi design. **Same features, same content, same behaviour — style and layout only.** No new features, no removed features, no data/API/schema changes.

In scope: design tokens, fonts, UI primitives (`src/ui/*`), the app shell (`src/shell/*`), every built page (Home, Organization, Agents, Approvals, Settings, notifications, command palette, AI panel, toasts, dialogs) and the honest empty states of unbuilt domain pages, desktop + tablet + mobile, and the e2e/a11y tests that assert shell structure.

Not in scope: building out Career / Socials / Outreach / Projects / Knowledge / Goals features (their Glass designs become the visual source for the phases that build them), light theme, new copy beyond what layout changes require.

</domain>

<decisions>
## Implementation Decisions

- **D-01 Design source of truth:** Claude Design project `faf225f7-8c4a-46ca-982e-fd969ee2f29d`, imported byte-exact into `design/glass/` (see `design/glass/INVENTORY.md`). `LifeOS Glass.dc.html` is the shell and imports one `Glass <Page>.dc.html` per screen; `Glass Mobile.dc.html` covers mobile; `Design Directions.dc.html` is the exploration that led here (reference only). Layout and visuals are authoritative; content is placeholder. The previous design (`design/*.dc.html`) is superseded for visuals but its behaviour/state specs (earlier UI-SPECs) still hold.
- **D-02 Replace, don't theme-switch:** Glass replaces the current look entirely. No toggle between old and new.
- **D-03 Fonts:** Instrument Serif (display, often italic) + Familjen Grotesk (UI) replace Geist; keep the self-hosted Material Symbols subset. Self-host via `next/font` (no runtime Google Fonts request). Check whether the design still uses a mono face anywhere (ids, code, numbers) and map accordingly.
- **D-04 Shell layout (from LifeOS Glass):** left sidebar → floating glass pill top nav (Home, Career, Socials, Outreach, Organization, Projects, Agents, Approvals + "More" menu for Knowledge, Goals, Settings); icons only below 1400px, labels at ≥1400px; logo pill (text hidden <1000px); right pill with Search ⌘K, notifications, Ask ⌘J (desktop), avatar. Desktop floating "Ask LifeOS anything…" bar at the bottom with 3 suggestion chips (hidden while the AI panel is open). Mobile (<760px): floating pill tab bar Home · Approvals · round Ask button · Agents · More, More opens a 2-column sheet. AI panel, notifications, command palette and toasts become floating glass cards. Existing keyboard shortcuts keep working.
- **D-05 Unbuilt domain pages:** render Glass-styled honest empty states (as today). Never ship the design's placeholder data.
- **D-06 Accessibility is not negotiable:** text contrast WCAG AA measured against the worst-case backdrop behind glass; solid (non-translucent) fallback under `prefers-reduced-transparency: reduce` and when `backdrop-filter` is unsupported; existing focus management, landmarks, skip link, labels and reduced-motion behaviour preserved; touch targets ≥44px on mobile.
- **D-07 Performance:** `backdrop-filter` is expensive — limit blur to floating chrome and panels, not every card in long lists; keep scrolling smooth on the VM-served app.
- **D-08 Verification:** owner checks visually on the homelab VM (desktop + phone); e2e and a11y specs updated to the new shell structure and kept green.
- Compact sidebar removed (owner-approved, UI-SPEC Relocated / Removed): the Ctrl+\ shortcut, the `lo_nav` cookie and the palette command 'Toggle compact sidebar' are gone with the sidebar; the only behaviour removal in this phase.
