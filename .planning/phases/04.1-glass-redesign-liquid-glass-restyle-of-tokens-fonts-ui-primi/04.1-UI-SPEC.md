# Phase 4.1 (Glass redesign) — UI Design Contract

> Style and layout only. Same features, same copy, same behaviour. Source of truth: `design/glass/LifeOS Glass.dc.html` (shell) + `design/glass/Glass <Page>.dc.html` (pages) + `Glass Mobile.dc.html`. `Design Directions.dc.html` was skimmed for rationale only (no mono face in the chosen direction; the alternatives are not decisions).
> Behaviour, state, copy and a11y contracts from `02-shell`, `03-agent-infrastructure-github`, `04-organization` UI-SPECs are inherited in full. Where this file and an older UI-SPEC disagree on a **visual** value, this file wins. Where they disagree on **behaviour/copy**, the older file wins unless listed in "Deliberate deviations from the design" or "Removed / relocated".
> Provenance: CONTEXT D-01..D-08 locked. No user questions asked: everything unresolved was settled by the design or by a measured WCAG constraint (marked **AA fix**). Defaults marked **default**.

## Design System

| Property | Value |
|---|---|
| Tool | none (hand-built `src/ui/*`; no shadcn, no `components.json`; shadcn gate not applicable, registry gate not applicable) |
| Preset | not applicable |

| UI font | Familjen Grotesk variable wght 400..700, `next/font/google`, `variable: "--font-grotesk"`, `subsets: ["latin"]`, `display: "swap"` |
| Mono | **Does not survive** as a face for labels/ids/numbers (Glass uses none). `--font-mono` is **re-pointed to Familjen Grotesk** so the ~140 existing `font-mono` usages become Grotesk labels with no per-file edit. | Theme | Dark only (D-02: replace, no toggle). `color-scheme: dark`. `viewport.themeColor` → `#121214`. |

`layout.tsx`: `<html className={`${serif.variable} ${grotesk.variable} ${symbols.variable}`}>`; body `font-family: var(--font-sans)`; `--font-sans: var(--font-grotesk), ui-sans-serif, system-ui, sans-serif`; `--font-display: var(--font-serif), Georgia, serif` (utility `font-display`). Familjen Grotesk is not guaranteed to ship `tnum`: do not rely on tabular numerals; verify clock/counters do not jitter, otherwise give those few elements `min-w` instead.

## Accessibility contract (D-06)

1. **Contrast**: all text tokens above meet ≥4.5:1 against the stated worst-case backdrop **in the places they are allowed**; chrome pills allow only `text`/`text-soft`/`cyan`/`amber`/`green` (≥4.74) — never `text-2`, `text-3`, `text-4`, `accent`. Non-text UI (focus ring `#64d2ff`, icon-only controls, round Ask fill) ≥3:1. Large text exemption is not relied on. Verify with a Playwright axe run (`@axe-core/playwright` already powers `a11y-shell`? if not, a computed-style contrast spot-check of the token table) at 1400 and 390.
2. **No `backdrop-filter` support**: `@supports not ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px)))` swaps the tier variables to solid fills.
3. **Reduced transparency**: `@media (prefers-reduced-transparency: reduce)` (where supported) and `@media (prefers-contrast: more)` apply the same solid variables **and** drop the canvas glow to a flat `#121214`: chrome `#26262a`, panel/menu/palette `#232326`, card `#202022`, borders `rgba(255,255,255,.22)` under `prefers-contrast: more`. Measured on the solids: `#8e8e93` = 4.81 on `#232326`, 5.21 on `#1c1c20`; `#aeaeb2` ≥ 7.0; `#64d2ff` ≥ 9.1.
4. **Focus**: global ring per Tokens; never removed; visible on every pill; focus order: skip link → logo → nav items → More → Search → bell → Ask → page → (Ask bar chips/bar are after `main` in DOM order so they do not trap tab order before content). Dialog traps, Esc, and focus restore are exactly the existing `useDialog` behaviour; the More **popover** is non-modal.
5. **Reduced motion**: global `prefers-reduced-motion` rule kept; pulses, scans, rises, slides stop. No information is conveyed by animation alone (running state also has text/label).
6. **Targets**: <760 and `pointer: coarse`: every interactive control ≥44×44 (header pills 54 tall, tab bar items 56, round Ask 56, sheet items 52, notification action pills, AI icon buttons, segmented items, inputs). ≥760 fine pointer: design sizes (≥26, above WCAG 2.5.8's 24 floor).
7. **Landmarks/labels**: `banner` (header), `navigation "Primary"` (one per viewport), `main`, assistant `complementary`/`dialog "LifeOS assistant"`, `dialog "Notifications"`, `dialog "Command palette"`, `dialog "More"` (mobile), `menu` (desktop More). Icon-only controls always carry `aria-label`; labels contain the visible text (More: Settings; Ask LifeOS). Skip link retained (`Skip to content`, targets `#main`).
8. Colour is never the only signal: approvals badge has a number, statuses have caps text, categories have names in the legend.
9. Zoom: nothing relies on `vh` clipping for essential content; the iOS 16px input rule in globals.css is kept.

## Performance contract (D-07)

- `backdrop-filter` is allowed **only** on: logo pill, nav pill, right pill, mobile tab bar, Ask bar, Ask-bar chips (≤3), AI panel, notifications panel, palette, and the time-grid sticky day header. That is ≤8 simultaneous layers on desktop (panels and the Ask bar are mutually exclusive: the bar hides when the AI panel opens), 4 on mobile.
- **Forbidden**: any blur on list rows, cards, tiles, table rows, scrims, dialogs, menus (menu tier is 94% opaque instead), tooltips, toasts (menu tier), skeletons, month cells.
- Blur radius capped at 40px; `saturate` ≤180%. Do not animate elements that carry `backdrop-filter` (only opacity/transform on first mount: `lo-rise`/`lo-slide`); no `transition: all`.
- Static glow layer is one fixed element (no `background-attachment: fixed` on a scrolling element, which repaints on scroll in Safari); `will-change` not set globally.
- The glass pill row must not make the scroll container re-composite per frame: header is `position: fixed`/sibling of the scroller, not inside it.
- Fonts: Instrument Serif (400 + 400 italic) and Familjen Grotesk (variable) latin subset, `display: swap`, preload on; no mono webfont. Material Symbols subset unchanged (`display: block`).
- Acceptance: owner scrolls Home, Organization week grid and Agents runs table on the VM-served app on desktop and phone without visible jank (D-08); if the 4-pill + sticky-header cost shows on phone, first fallback is dropping the time-grid sticky blur, second is `saturate` removal.
