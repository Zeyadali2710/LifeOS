## Pattern Assignments

### `src/app/globals.css` (config, tokens)

**Analog:** itself. Keep the three-part structure: `:root` raw vars (l.3-63), `@theme inline` mapping vars to Tailwind (l.65-111), then globals + keyframes (l.113-169). Do not restructure; edit values and rename per the UI-SPEC rename map.

**Token -> utility mapping convention** (`globals.css` 65-94): every utility colour is `--color-X: var(--X)` inside `@theme inline`, so `bg-surface`, `text-text-2`, `border-line` all derive from there. New tokens (`--accent`, `--accent-solid`, `--text-soft`, `--cyan`, `--cyan-soft`, `--purple`, `--purple-text`) need BOTH a `:root` var and a `--color-*` line or the Tailwind class will not exist.
```css
@theme inline {
  --color-text-2: var(--text-2);
  --color-indigo: var(--indigo);      /* becomes --color-accent: var(--accent) */
  ...
  --font-sans: var(--font-geist-sans), ui-sans-serif, system-ui, sans-serif;   /* -> var(--font-grotesk) */
  --font-mono: var(--font-geist-mono), ui-monospace, monospace;               /* -> re-point to grotesk */
  --radius-4: 4px; ... --radius-16: 16px;      /* add 18,20,22,24,26,28,30 in same one-line style */
  --breakpoint-tab: 720px;  --breakpoint-desk: 1100px;   /* tab -> 760, add mid 1000, wide 1400 */
}
```
Gotcha: `@theme inline` has self-referencing lines `--shadow-float: var(--shadow-float);` (l.102-106). Renaming to `--shadow-chrome/panel/card` must keep both sides consistent (or drop the theme line and use `shadow-[var(--shadow-card)]`).

**Keyframes / reduced motion** (l.136-149): keep names, change only colours. Reduced-motion block stays verbatim:
```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { animation: none !important; transition: none !important; }
}
```
**Unlayered iOS 16px rule** (l.166-169) stays. Glass tier fallbacks (`@supports not (backdrop-filter...)`, `prefers-reduced-transparency`, `prefers-contrast: more`) go after the `:root` block as variable overrides of the tier vars, so `@utility glass-*` only reads variables.

**Body background** (l.114-125): the two radial gradients on `body` are removed; replace with a fixed aria-hidden glow element in `app-shell.tsx`.
