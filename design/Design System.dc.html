Agent states

The diamond is LifeOS's mark for intelligence: the Orchestrator, AI inputs and insights. Domain agents use a round status dot. Only running states move. Agent loading (a scanning line with a named action) is deliberately different from data loading (a neutral shimmer skeleton).
