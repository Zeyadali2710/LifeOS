# ADR-003: Postgres 17 + pgvector, Drizzle ORM, checked-in migrations
Status: Accepted (2026-10-07)
## Decision
Postgres is the single source of truth. Drizzle schema in TS, SQL migrations generated by drizzle-kit and committed. pgvector for semantic retrieval beside relational data.
## Why
Relational integrity for a normalized domain model; typed queries without a heavy ORM runtime; one database to back up.
## Rejected
SQLite (concurrency between web+worker, no pgvector/LISTEN), separate vector DB (second source of truth).
